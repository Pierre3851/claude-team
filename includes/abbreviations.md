*[ADR]: Architecture Decision Record — court document qui consigne une décision technique, son contexte, les alternatives écartées et ses conséquences.
*[CLI]: Command Line Interface — programme qu'on utilise en tapant des commandes dans un terminal.
*[venv]: Environnement virtuel Python — dossier isolé qui contient l'interpréteur et les paquets propres à un projet.
*[backlog]: Liste ordonnée des tâches à réaliser.
*[prompt]: Texte d'instruction envoyé au modèle.
*[token]: Unité de texte (environ ¾ de mot) que le modèle lit et produit ; la consommation se compte en tokens.
*[tokens]: Unités de texte (environ ¾ de mot) que le modèle lit et produit ; la consommation se compte en tokens.
*[hook]: Script que Claude Code exécute automatiquement à un moment précis (avant un outil, après une modification…), indépendamment de ce que décide le modèle.
*[MCP]: Model Context Protocol — standard qui permet de brancher des outils externes (bases de données, services web) sur Claude Code.
*[OWASP]: Open Worldwide Application Security Project — organisation qui publie notamment le Top 10 des failles de sécurité web les plus courantes.
*[PII]: Personally Identifiable Information — donnée permettant d'identifier une personne.
*[PID]: Process IDentifier — numéro attribué par le système à un programme en cours d'exécution.
*[heartbeat]: Fichier ou signal mis à jour régulièrement par un traitement long pour prouver qu'il est toujours vivant.
*[frontmatter]: En-tête YAML placé entre deux lignes --- au début d'un fichier Markdown, qui contient des réglages.
